**🚨 Штрафное задание**

- **Integration Mock:** Реализован Mock-объект, что позволяет тестировать логику без реального подключения к БД.
- **Advanced Mocking:** Использование MockHandler в Guzzle для имитации ответов от внешних API.

**⚙️ Как запустить тесты**
Чтобы запустить тестирование через Docker , выполните команду в корне проекта:
```bash
docker run --rm -v \${PWD}:/app -w /app php:8.2-fpm php www/vendor/bin/phpunit tests
```
